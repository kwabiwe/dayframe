## Motion and evidence contract

System text size, Bold Text, and width changes update presentation; expansion and existing sheet/navigation actions keep their current owners. React Native uses the existing local layout transitions for row reflow; SwiftUI owns only its native Calendar header rendering. Rows grow intrinsically, stable entry/group keys preserve state, stale measurements are ignored, and typography never triggers writes. No decorative animation is added. Reduce Motion keeps the same content/actions with immediate or existing reduced reflow. Any change to entry/deletion, Review, editor, or Calendar gestures remains owned by the existing component.

Diagnostic fixtures contain synthetic text and geometry only. Record source and bundle identity, fixture ID, OS/runtime, device/simulator, viewport, pixel ratio, actual font scale/content-size category, Bold Text, appearance, Reduce Motion, font/line metrics, text/ancestor frames, clipping owner, and PASS/FAIL/NOT RUN. Do not log descriptions, tags, account/profile values, locations, Health data, credentials, or screenshots containing user data.
